此前人工上报生成的待受理工单未写入负责人，运维人员虽可见“接单”入口，但后端会拒绝操作。已修复为按 `user_sites` 站点责任关系自动写入现场运维人员，仍保留“待受理 -> 接单 -> 签到 -> 处置”的移动端流程。
