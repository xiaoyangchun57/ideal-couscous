## 视觉交互快速检查

- [ ] 三秒内能找到当前任务、风险状态和主操作。
- [ ] 文字、标签、按钮和表单在当前屏幕上清晰可读。
- [ ] 主操作与次操作层级明确，危险操作不易误触。
- [ ] 颜色之外还有文字或图标表达状态。
- [ ] 加载、成功、失败、待同步有及时且可理解的反馈。
- [ ] 空状态、无权限、网络失败给出下一步。
- [ ] 返回、刷新、跨端跳转后仍知道正在处理什么。
