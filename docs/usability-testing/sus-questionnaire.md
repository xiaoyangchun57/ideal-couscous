# SUS 可用性问卷

每名参与者完成自己角色全部任务后填写。请按直觉选择 1 至 5：1=非常不同意，5=非常同意。

| 编号 | 陈述 | 评分 |
| --- | --- | --- |
| 1 | 我愿意经常使用这个系统。 | |
| 2 | 我觉得这个系统不必要地复杂。 | |
| 3 | 我觉得这个系统容易使用。 | |
| 4 | 我认为需要技术人员协助才能使用这个系统。 | |
| 5 | 我觉得系统中的功能整合得很好。 | |
| 6 | 我觉得系统存在太多不一致之处。 | |
| 7 | 我认为大多数人能很快学会使用这个系统。 | |
| 8 | 我觉得这个系统使用起来很笨拙。 | |
| 9 | 我使用这个系统时很有信心。 | |
| 10 | 在真正使用前，我需要学习很多东西。 | |

## 计分

- 奇数题得分：填写分数减 1。
- 偶数题得分：5 减填写分数。
- 将十题调整后得分相加，再乘以 2.5，得到 0 至 100 的 SUS 分数。
- 首轮只记录角色均值、最低项和用户原话，不设放行阈值。不得用高分掩盖 P0/P1 问题。

## 结束问题

1. 你最放心系统的哪一部分？
2. 你最不放心哪一部分？
3. 如果只能改一处，你希望改什么？
4. 你是否敢在真实工作中独立提交？为什么？
