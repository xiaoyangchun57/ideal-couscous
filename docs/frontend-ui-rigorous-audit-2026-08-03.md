## 4. 系统性根因（给决策者看）

阶段二重构的执行策略是"逐页改造、能收编就收编"，**没有先冻结一套唯一页面模板**。结果：
1. 自造 `WorkspacePage` 取代既定 `ManagementPage`，规范文档变成废纸（W2）；
2. 大页（cockpit/maintenance 等）因体积被跳过，成为"法外之地"（W3）；
3. 小程序把 `.tabs/.filter-bar` 合并成 `.seg-strip` 但只覆盖 4/10 调用点，且漏改的页面留下弱可示性（M6、M12 的 `.seg-opt`）；
4. **保命线（错误边界、失败兜底）从来不在重构清单里**——这是 AI 开发最典型的盲区：功能跑通即"完成"，容错不在验收标准内。

净效果：一致性**局部收敛、整体仍分裂**，且**韧性倒退**（无任何崩溃兜底）。
