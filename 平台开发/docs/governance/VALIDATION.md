# 验证指南：按变化选择证据

开发自测、Review、冻结或真实UI验收触发对应部分；只读讨论不触发。测试使用隔离数据库、临时上传目录和独立端口，不触碰真实用户库、线上容器或用户在用服务。

## 改动验证

- 开发只跑改动和直接相邻回归；唯一候选冻结时运行一次本轮约定的最终检查。相同对象和风险已有可信结果时复用，代码/配置/状态变化后重验受影响部分。报告来源和适用对象，不能把历史计数称为本次运行。
- 权限、状态迁移、资源占用和关键写操作覆盖适用的成功、越权、不存在、冲突、重复与失败回滚；不相关分支不机械套用。已知绕过直接调用服务端验证零副作用。
- 契约、媒体地址、状态语义或默认行为变化，应覆盖实际旧/新输入、必要写后重读和至少一个真实下游消费者。夹具来自真实上游形态，不能用理想响应绕过集成。
- React改动运行相关测试、lint、build；后端运行相关unittest及编译；小程序运行相关Node测试及JS语法检查。纯文档不跑业务测试。
- 修改前明确原可用闭环，实现后先确认它仍能由真实形态输入贯通，再验证新增目标。新增人工前置、写入后不可见或下游断链不能用局部PASS抵消。

## 真实UI

- 当前截图足以说明单页面可见问题时直接作为复现证据，不重复复现。涉及角色、跨页面、环境或后续业务行为时使用当前真实环境。
- 修正后需要真实UI的部分，由用户或当前已授权执行者验收；不自动创建subagent或独立验收任务。API、静态截图或开发者工具结果不冒充未执行的平台验收。
- 按风险记录实际结果及NOT RUN/SKIPPED；截图仅支持其可见结论，不能证明未展示的保存、权限或下游行为。

## 本机隔离验收环境准备

- 每条验收基线的专用隔离数据库幂等准备admin/password管理员账号：启用、不强制首改；通过真实登录接口或UI验证后交付。
- 此固定账号只用于本机隔离环境，不写入体验版、生产、真实用户库、发布包或生产配置，不作为线上恢复方案。
- 端口按隔离环境选择并交付实际地址，不沿用历史固定端口规则。保留用户正在使用的服务和工具，不为验收擅自重启。

发布侧数据库/备份验证成本与恢复要求见RELEASE.md，不重复执行开发全量套件。
