## 3. 实现契约

1. **双协议分帧**：同一连接按明确前导识别 `7E 7E` 与 `## + 四位长度`；支持拆包、粘包、多帧、前导噪声、长度上限和超时。一个协议的异常不得吞掉随后另一个协议的完整帧。
2. **HJ212 校验与认证**：验证长度、正文边界和 CRC；以 `MN` 选择启用端点并校验 `PW`，使用恒定时间比较。未知站点、错误凭证、错误长度/CRC均留存为隔离事实，不规范化、不回显敏感字段。
3. **原始事实**：完整 HJ212 帧先追加写入原始层，再进入解析尝试；通过版本化迁移显式记录协议族和解析器版本，不能靠后续猜首字节。重复接收仍保留原始记录，规范化结果幂等。
4. **时间语义**：`received_at` 是平台接收时间；`DataTime` 是观测时间；`QN` 只作请求/报文标识，不能冒充观测时间。按端点时区转换并沿用现有有效期映射规则。
5. **数据语义**：首批仅将认证通过的 `CN=2011` 投影为实时观测。合法 0 必须保留，缺失不补 0；`Flag=N` 可作为有效候选，`Flag=F` 不得进入有效曲线。未知 Flag、未知因子和纯数字因子保留原码并形成可诊断质量事项，不得编造名称或单位。
6. **其他命令与应答**：`3020/3041/9015` 均不生成监测值。首批实现证据明确的 `3020 -> 9011/QnRtn=1` 最小应答，且只在完整校验、认证和原始持久化成功后发送；持久化或认证失败不得确认。`2091/3041/9015` 以及 `2011` 是否另需应用层应答，在没有协议依据前只分类留存、不猜测回复。不得发送校时或控制命令；现有二进制协议 ACK 不得回归。
7. **映射**：HJ212 因子映射进入现有标准化模型，映射必须可配置且有有效期；`022/027/029/030` 作为保留原码的协议别名进入定义和映射层，不能改写为其标准码；`005` 不得硬编码为业务指标，也不得写旧 `sensor_data`。
