# 组件选型决策树

> 遇到新需求，不知道该用哪个组件？顺着问题往下找。
> 原则：能组合现有组件，就不新增组件。

---

## 1. 我需要展示一个"状态"

→ **Status Chip 状态标签**

先确定语义色：
- 成功/正常/已完成/已通过 → success（绿）
- 进行中/信息提示 → info（蓝）
- 待审核/待补拍/待整改/等待用户动作 → warning（橙）
- 提示级告警 → notice（黄）
- 异常/失败/驳回/危险 → error（红）
- 业务类型（巡检、工单、水厂……） → default（灰）

> 不要用彩色区分业务类型，这是铁律第 1 条。

---

## 2. 我需要让用户"选一个选项"

### 选项很少（2-4 个），且在页面顶部切换视图
→ **Segmented Control 分段控件**

例：站点 / 试剂、全部 / 待处理 / 已完成

### 选项很多，或选项是表单字段的值
→ **Action Sheet 操作表**（简单选项列表）
→ **Bottom Sheet + 列表**（选项带描述、带搜索、或超过 6 个）

### 是/否 二选一的开关设置
→ **Switch 开关**

### 多个选项可同时选
→ **Checkbox 列表**（用 List Row + 勾选图标组合）

---

## 3. 我需要"弹出来做点事"

### 只是选一个简单选项（2-6 个）
→ **Action Sheet 操作表**

例：删除确认、分享方式选择、排序方式

### 内容较复杂（表单、详情、多步操作）
→ **Bottom Sheet 底部面板**

例：登记更换、完成标定、筛选条件设置、新建条目

### 确认一个破坏性操作
→ **Action Sheet + 红色危险选项**（底部居中"删除"按钮）

不要用系统 Alert 做复杂确认，除非是极其简单的"确定/取消"。

---

## 4. 我需要"放一组操作按钮"

### 在页面底部，承载页面主动作
→ **Action Bar 底部动作栏**

- 单按钮：全宽 Primary
- 双按钮：左 Secondary + 右 Primary
- 三图标 + 按钮：图标在左，按钮在右

### 在卡片内，多个快捷入口
→ **Quick Actions 快捷入口**

- 不超过 8 个，过多改用列表导航
- 宫格布局，0.5px 细线分隔
- 每项高度 64px，按下灰底反馈

### 在导航栏右侧
→ 最多 2 个图标按钮或 1 个文字按钮
- 图标用 22px，点击热区 ≥ 44×44px

---

## 5. 我需要"展示列表数据"

### 同层级的简单信息、设置项、详情入口
→ **List Row 列表行** + **Card 分组卡片**

标准结构：左侧图标 + 主标题 + [副标题] + 右侧箭头/状态/开关

### 信息分组，有 Section 标题
→ **Card 分组卡片**（16px 圆角，白底）

同一组信息放一个卡片里，不同组分隔 10px。

### 时间顺序的操作记录
→ **Timeline 时间线**

最新记录在最上面，每个节点有时间+操作人+动作+状态变化。

### 图片/照片
→ **Photo Grid 照片九宫格**

支持浏览、添加、删除。

---

## 6. 我需要"表达进度"

### 线性进度（任务完成度、上传进度）
→ **Progress 条形进度指示器**

### 环形进度（百分比、占比）
→ **Progress 环形进度指示器**

进度颜色用语义色：
- 进行中 → primary（蓝）
- 已完成 → success（绿）
- 待处理 → warning（橙）
- 异常 → error（红）

---

## 7. 我需要"输入内容"

### 一行短文本（姓名、编号、地址）
→ **Input 输入框**

### 多行文本（备注、原因、描述）
→ **Textarea 文本域**

### 搜索过滤列表
→ **Search Bar 搜索栏**

### 数字 / 日期 / 选项选择
→ 用原生 picker 组件，样式对齐 Input

---

## 8. 我需要"提示/通知用户"

### 未读数量 / 红点
→ **Badge 角标**

数字角标在右上角，最多 99+。

### 操作结果反馈
→ **Toast**（轻量提示，2 秒自动消失）
→ **成功页 / 失败页**（重要操作的明确反馈）

### 系统级告警/通知
→ **首页告警入口 + 告警列表页**（不弹 Modal 打断用户）

---

## 9. 空状态 / 加载 / 错误

| 场景 | 组件 | 有没有操作按钮 |
|------|------|---------------|
| 列表为空，可主动添加 | Empty State (no-data) | 有（添加按钮） |
| 搜索无结果 | Empty State (no-result) | 无 |
| 加载失败 | Empty State (error) | 有（重新加载） |
| 无权限 | Empty State (permission) | 无 |
| 首次加载 | 骨架屏 / Loading 指示器 | 无 |
| 上拉加载更多 | 底部 Spinner + "加载中..." | 无 |

---

## 找不到合适的组件？

1. 再看一遍：是不是可以用现有组件组合实现？
2. 查 `CONTRIBUTING.md` 中的"新增组件流程"
3. 三个条件同时满足才值得新增：
   - 在至少 3 个不同页面中复用
   - 有明确的使用场景和边界
   - 现有组件组合不了（或组合成本极高）
