> 状态：`REAL_UI_REWORK_DISTRIBUTED`。这是合并版本的集成验收，不把全部问题归责给单个 PR；不授权合并、冻结或部署。

## 共同规则

- 每个结果负责人自行建立本领域的专业设计师 Agent 和开发 Agent；新布局、信息层级、组件结构和图标方案必须先由本领域设计师 Agent 形成基线。
- 设计未完成的结构性问题标记 `DESIGN_REQUIRED`，不得自行试做一版。
- Web 真实 UI已通过。本文件只处理小程序；隔离验收使用的 BOM 临时补丁不等于正式代码已修复。

## 主线

主线自己的设计师 Agent 与开发 Agent 负责公共 TabBar 图标、公共页头固定与安全区、动态 sticky 高度契约、首页运维概览、首页试剂分类计数和管理员站点范围文案。不改 A/B 业务文件。

## A：站点与试剂

A 自行建立站点与试剂领域的设计师 Agent，负责站点/试剂一级模式与二级筛选层级、试剂卡片、登记更换/完成标定弹窗的静态方案。设计完成前，开发 Agent 只处理可独立确认的机械问题：正式吸收 `pages/index/index.wxss` 文件头 BOM；两类 Sheet 打开/关闭时隐藏并恢复原生 TabBar；保留提交失败输入和幂等键。设计交付后再接线筛选、卡片、弹窗、长内容和动态 sticky 偏移。不得修改首页、公共 TabBar、公共导航组件和试剂后端。

回传：分支与不可变 SHA、文件清单、采用的设计基线、自动测试、微信开发者工具编译、真实 UI `NOT RUN` 项。停点为主线 Review，不合并、不部署。

回传：权限矩阵、前后端文件、成功/越权/他人数据测试和真实 UI 状态。未经主线确认不得混入 PR #4 或扩展其他计划权限。
