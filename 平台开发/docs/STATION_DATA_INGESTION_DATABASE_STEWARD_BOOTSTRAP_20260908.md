### 三项实施硬约束

1. **未知站点与未绑定站点必须分开**：完全未知、无法匹配受信端点或无法验证凭据的站号不得成功应答，只能受限留证、限速并关闭连接；只有“已知且凭据验证通过的端点，但尚未绑定业务站点”才可在原始帧持久化后应答并进入待映射隔离。不得用成功应答掩盖未授权来源。
2. **原始帧本身是敏感数据**：协议密码位于原始字节中，因此数据库、WAL、归档和备份都按敏感运行数据处理。完整原始字节不得进入普通日志、API、Web页面、测试夹具或回传；访问仅限接入/数据库维护角色。生产开放前必须由发布或维护任务确认受限文件权限、备份加密或等效静态保护、独立故障域副本和恢复授权链。
3. **可空仪器ID不能直接承担唯一性**：SQLite唯一约束允许多个`NULL`。批次内因子唯一性必须使用非空规范化仪器身份、表达式/部分唯一索引或等效结构，直接测试“无仪器归属时重复写入”不会产生重复观测。
